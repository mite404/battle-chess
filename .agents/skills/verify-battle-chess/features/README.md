# Battle Chess verification map

- [Play a match](match.md). Legal moves, special moves, AI, undo, and saved games.
- [Watch captures](captures.md). All six characters and the theatre's saved match.
- [Use controls](controls.md). Hints, rotation, sound, position loading, and narrow layout.

Game state and UI are in `src/main.js`. Characters and animations are in `src/scene.js`. Sound
effects are in `src/audio.js`. Shared files mean any change can affect multiple journeys.
